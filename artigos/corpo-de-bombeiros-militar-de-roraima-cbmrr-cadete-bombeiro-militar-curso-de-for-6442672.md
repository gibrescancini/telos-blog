# Concurso CBMRR para Cadete Bombeiro Militar com salário de R$ 120,00

O concurso é para ingresso no Curso de Formação de Oficiais Combatentes do Corpo de Bombeiros Militar de Roraima.

Publicado originalmente em https://umtelos.com.br/blog/corpo-de-bombeiros-militar-de-roraima-cbmrr-cadete-bombeiro-militar-curso-de-for-6442672

## O que é

É um concurso público para provimento de vagas ao Curso de Formação de Oficiais Bombeiros Militares (CFOBM) para o Quadro de Oficiais Combatentes (QOCBM) do Corpo de Bombeiros Militar de Roraima.


## Quanto paga e taxa

- rotulo: Taxa de inscrição; valor: R$ 120,00

## Quem pode se inscrever

Podem se inscrever candidatos que atendam aos requisitos do edital para o cargo de Cadete Bombeiro Militar.


## Quando é cada coisa

As inscrições vão de 11 de agosto de 2026 a 24 de agosto de 2026.

A prova está marcada para 27 de setembro de 2026.


## Como é a prova

A prova inclui uma redação.


## Para quem estuda

- Estude as matérias previstas para o cargo de Cadete Bombeiro Militar.
- Prepare-se para a redação.
