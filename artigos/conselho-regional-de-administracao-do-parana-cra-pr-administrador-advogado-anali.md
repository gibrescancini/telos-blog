# Concurso do Conselho Regional de Administração do Paraná

Oportunidades para cargos de níveis fundamental, médio e superior com vagas imediatas e cadastro de reserva.

Publicado originalmente em https://umtelos.com.br/blog/conselho-regional-de-administracao-do-parana-cra-pr-administrador-advogado-anali

## O que é o concurso

O Conselho Regional de Administração do Paraná realiza concurso público para preenchimento de vagas e formação de cadastro de reserva em cargos de níveis fundamental, médio e superior.


## Remuneração e vagas

Os salários variam conforme o nível de escolaridade exigido para cada cargo.

- rotulo: Nível superior; valor: R$ 8.093,44
- rotulo: Agente Administrativo; valor: R$ 4.092,94
- rotulo: Nível fundamental; valor: R$ 3.107,82
- rotulo: Vagas imediatas; valor: 1 para Administrador e 1 para Analista Jurídico
- rotulo: Cadastro de reserva para Administrador; valor: 50
- rotulo: Cadastro de reserva para Advogado; valor: 25
- rotulo: Cadastro de reserva para Analista de Sistemas; valor: 25
- rotulo: Cadastro de reserva para Analista Jurídico; valor: 25
- rotulo: Cadastro de reserva para Contador; valor: 25
- rotulo: Cadastro de reserva para Agente Administrativo; valor: 51
- rotulo: Cadastro de reserva para Motorista; valor: 25
- rotulo: Cadastro de reserva para Auxiliar de Serviços Gerais; valor: 25

## Quem pode participar

Podem se inscrever candidatos com nível fundamental, médio ou superior, conforme o cargo pretendido.


## Cronograma e etapas

As inscrições ocorrem entre 22 de junho de 2026 e 23 de julho de 2026.

A prova está marcada para 13 de setembro de 2026.

- rotulo: Taxa de inscrição para nível superior; valor: R$ 74,00
- rotulo: Taxa de inscrição para nível médio/técnico; valor: R$ 70,00
- rotulo: Taxa de inscrição para nível fundamental; valor: R$ 69,00
- rotulo: Jornada semanal para a maioria dos cargos; valor: 40 horas
- rotulo: Jornada semanal para Advogado; valor: 30 horas

## Como será a prova

O concurso terá prova objetiva de múltipla escolha com 50 questões para todos os cargos.

Haverá prova discursiva para cargos de nível médio e superior.

Candidatos de nível superior também passarão por avaliação de títulos.

- rotulo: Cotas para pessoas com deficiência; valor: 5%
- rotulo: Cotas para negros; valor: 25%
- rotulo: Cotas para indígenas; valor: 3%
- rotulo: Cotas para quilombolas; valor: 2%

## Para quem estuda

- Para cargos de nível superior, estude conteúdos específicos da área de atuação, como administração, direito, sistemas ou contabilidade.
- Para cargos de nível médio e superior, prepare-se para a prova discursiva com temas relacionados ao cargo pretendido.
- Para todos os cargos, estude conhecimentos gerais e específicos abordados na prova objetiva de múltipla escolha.
