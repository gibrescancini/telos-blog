# Concurso para Analista de Desenvolvimento de Sistemas na CRAISA

Oportunidade para profissionais de nível superior na área de tecnologia da Companhia Regional de Abastecimento Integrado de Santo André.

Publicado originalmente em https://umtelos.com.br/blog/companhia-regional-de-abastecimento-integrado-de-santo-andre-craisa-303-analista

## O que é o concurso

A Companhia Regional de Abastecimento Integrado de Santo André (CRAISA) realiza concurso público para o cargo de Analista de Desenvolvimento de Sistemas.

O objetivo é formar cadastro de reserva para futuras contratações.


## Quem pode se inscrever

Podem participar candidatos com ensino superior completo.


## Como é a prova

O processo seletivo é composto por duas fases: prova objetiva e prova discursiva.


## O que estudar

Os candidatos devem se preparar para as provas objetiva e discursiva, conforme o conteúdo programático estabelecido para o cargo de Analista de Desenvolvimento de Sistemas.


## Para quem estuda

- Estude os conteúdos específicos relacionados ao desenvolvimento de sistemas.
- Prepare-se para questões objetivas e discursivas sobre a área de atuação.
