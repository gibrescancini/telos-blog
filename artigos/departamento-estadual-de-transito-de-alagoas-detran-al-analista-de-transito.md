# Concurso do DETRAN/AL para Analista de Trânsito

Oportunidade para profissionais de nível superior no Departamento Estadual de Trânsito de Alagoas.

Publicado originalmente em https://umtelos.com.br/blog/departamento-estadual-de-transito-de-alagoas-detran-al-analista-de-transito

## O que é o concurso

O concurso público do Departamento Estadual de Trânsito de Alagoas (DETRAN/AL) visa formar cadastro de reserva para o cargo de Analista de Trânsito.

A seleção é destinada ao provimento de vagas em cargos de nível superior.


## Quem pode se inscrever

Podem participar candidatos com nível superior de escolaridade.


## Como é a prova

O concurso será composto por provas objetivas e discursivas.


## O que estudar

Os candidatos devem se preparar para as provas objetivas e discursivas do cargo de Analista de Trânsito.


## Para quem estuda

- Estude os conteúdos relacionados às provas objetivas para Analista de Trânsito.
- Prepare-se para a elaboração de questões discursivas conforme o cargo.
