# Concurso da Companhia Regional de Abastecimento Integrado de Santo André para nível superior

Processo seletivo da CRAISA oferece cadastro de reserva para candidatos com formação superior.

Publicado originalmente em https://umtelos.com.br/blog/companhia-regional-de-abastecimento-integrado-de-santo-andre-craisa-nivel-superi

## O que é o concurso

A Companhia Regional de Abastecimento Integrado de Santo André realiza concurso público para formação de cadastro de reserva em cargos de nível superior.

O processo seletivo não especifica o número de vagas ou o salário oferecido.


## Quem pode se inscrever

Podem participar candidatos com formação de nível superior, conforme exigido para o cargo.


## Como é a prova

O concurso é composto por duas fases: prova objetiva e prova discursiva.


## O que estudar

Os candidatos devem se preparar para as provas objetiva e discursiva, conforme o conteúdo programático estabelecido para o cargo de nível superior.


## Para quem estuda

- Estude os conteúdos específicos relacionados ao cargo de nível superior.
- Prepare-se para questões objetivas e para a elaboração de texto discursivo.
