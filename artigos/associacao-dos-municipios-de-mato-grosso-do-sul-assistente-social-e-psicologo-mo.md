# Concurso Público da ASSOCIAÇÃO DOS MUNICÍPIOS DE MATO GROSSO DO SUL

Agora é o momento de se preparar para o concurso da ASSOCIAÇÃO DOS MUNICÍPIOS DE MATO GROSSO DO SUL.

Publicado originalmente em https://umtelos.com.br/blog/associacao-dos-municipios-de-mato-grosso-do-sul-assistente-social-e-psicologo-mo

## O que é o concurso

O concurso público é para contratação temporária de profissionais em Mato Grosso do Sul.

As vagas são de cadastro reserva e há múltiplas áreas de atuação.

## Quem pode se inscrever

Os candidatos devem ter Graduação completa em nível superior.

## Fases do concurso

O concurso terá Prova Objetiva e Discursiva.

## Para quem estuda

- Para quem está se preparando para o cargo de Assistente Social, é importante estudar as matérias relacionadas à assistência social.
- Para quem está se preparando para o cargo de Psicólogo, é importante estudar as matérias relacionadas à psicologia.
- Para quem está se preparando para o cargo de Motorista, é importante estudar as matérias relacionadas à condução de veículos.
